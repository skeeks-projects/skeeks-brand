# Favicon продуктов SkeekS

Общий комплект фирменных favicon. Создан 1 октября 2026; с 2 октября 2026 хранится в пакете skeeks/skeeks-brand (каталог brand/favicons).

## Выбранный вариант

Тёмная скруглённая плашка #141b25 и адаптированная для малых размеров лампочка. Основной логотип компании не заменяется этой адаптацией. За пределами плашки прозрачность.

| Каталог | Продукт | Цвет |
| --- | --- | --- |
| skeeks | Компания SkeekS | Лампочка #8dce42; лучи #ee4d7d, #39afe0, #efd740, #8dce42, #28c3c5 |
| platform | SkeekS Платформа | #a6de58 |
| goods | SkeekS Товары | #efd740 |
| ai | SkeekS AI | #64dcdb |

В каждом каталоге:
- favicon.svg — редактируемый вектор, viewBox 0 0 128 128;
- favicon-16.png, favicon-32.png, favicon-48.png, favicon-120.png;
- favicon.ico — три изображения: 16, 32 и 48 px.

Версия 16px имеет усиленные линии. Не заменять её простым уменьшением PNG 120px.
preview.png — общий просмотр с примерами на светлом и тёмном фоне.
explorations/ — сохранённые пробы: a (прозрачный фон), b (плашка), circle (круг). Это не выбранные версии. Круг тестировался на skeeks.com, затем пользователь попросил вернуть плашку. Набор форматов у проб неполный.

## Установка

На skeeks.com и skeeks-platform.ru выбранный вариант установлен через штатное поле favicon в настройках сайта CMS (/~sx/cms/admin-cms-site-info). PNG 120x120 загружается в файловое хранилище, его ID передаётся в cms_site_update.favicon_storage_file_id. После изменения прочитать настройки и проверить link rel=icon в HTML.

На skeeks.com также отдельно обновлён корневой /favicon.ico. При замене синхронизировать его с выбранным вариантом и сохранять резервную копию. Не добавлять жёсткие ссылки в layout и не переопределять штатный вывод favicon.

Предыдущая запись файла в CMS может удаляться при замене: для отката сохранять исходный файл, а не рассчитывать только на старый ID.

Для goods и ai здесь подготовлены файлы; их публикация на сайтах в рамках этой работы не выполнялась.

## Как добавлять продукты и обновлять комплект

1. Согласовать имя продукта и цвет. Сохранять общий фон, геометрию и пропорции знака.
2. Добавить запись в products в build.cjs. Для нового геометрического варианта сначала создать отдельный каталог в explorations/.
3. Запустить node brand/favicons/build.cjs из корня пакета. Нужен sharp: npm i sharp рядом или NODE_PATH с каталогом node_modules, где он установлен.
4. Проверить SVG и PNG, ICO 16/32/48, прозрачные углы, читаемость 16px на светлом и тёмном фоне. Генератор сохраняет файлы только в этой папке, ничего не публикует.
5. Обновить таблицу и сведения о фактической публикации. Переносить на сайт через его CMS; отдельно обновлять корневой ICO при необходимости.

Генератор перезаписывает выбранные комплекты и preview.png; ручные изменения геометрии в SVG переносить в mark() генератора до пересборки. При добавлении большого числа продуктов расширить раскладку preview.png.
