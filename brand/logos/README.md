# Логотипы SkeekS и продуктов

Комплект от 2026-10-02. Эталон пользователя — логотип в шапке skeeks-platform.ru (композиция E). Публикация на сайтах в этой задаче не выполнялась.

## Состав

- skeeks/ — компания: лампочка и skeeks в одну строку, надпись восстановлена Nunito 400; исходный корпоративный PNG отдельно в sources/.
- platform/ — SkeekS Платформа, эталон композиции.
- goods/ — SkeekS Товары, та же композиция с заменой названия.
- ai/ — SkeekS AI, та же композиция с заменой названия.
- preview.png — общий просмотр на светлом и тёмном фоне (цветные панели не входят в файлы логотипов).
- sources/ — оригинальные PNG лампочки и корпоративного логотипа, Nunito variable TTF и его OFL-лицензия.

Для каждого продукта: logo-on-dark.svg (белые надписи), logo-on-light.svg (тёмные надписи #141b25), PNG и lossless WebP высотой 64, 128, 256 px для обеих версий. Все файлы имеют прозрачный фон. Число в имени означает высоту всего файла, ширина пропорциональна названию.

## Важно об SVG и качестве

SVG автономный: надписи переведены в контуры, устанавливать Nunito для просмотра не нужно. Оригинальная лампочка сохранена без перерисовки как встроенный PNG 133x138. Это гибридный SVG, не полностью векторный знак. Экспорт больших PNG не добавляет деталей лампочке. Для крупной печати нужен исходный вектор лампочки от автора; заменить встроенное изображение им, сохранив композицию. Не использовать упрощённую лампочку favicon вместо основного знака.

Пропорции взяты из common/themes/platform/assets/src/css/platform.css проекта skeeks-platform.ru: высота лампочки H, отступ до текста 0.16H, skeeks — Nunito 400 размером 0.34H, название продукта — Nunito 800 размером 0.57H, межбуквенное расстояние -0.025em, штрих 0.32H на 0.055H, цвет штриха соответствует favicon продукта: Платформа #a6de58, Товары #efd740, AI #64dcdb. У всех продуктовых логотипов одинаковые цветные лучи и зелёная лампочка. Цветовой акцент favicon переносится на штрих рядом со skeeks; оригинальная лампочка и её лучи сохраняют фирменные цвета.

## Добавление продукта

1. Добавить согласованное название и slug в products в build.py. Не превращать автоматически модули платформы в самостоятельные бренды.
2. Сохранить общую композицию и шрифт; цвет штриха задавать в products в соответствии с favicon продукта. Проверить длинные названия и границы файла.
3. Запустить python brand/logos/build.py (из корня пакета) (зависимость fonttools), затем node brand/logos/export.cjs (зависимость sharp).
4. Проверить preview.png и прозрачные PNG на обоих фонах. Надписи должны оставаться контурами; внешние ссылки и зависимости SVG не нужны.
5. Дополнить этот README. Генераторы сохраняют результаты только в этом каталоге и ничего не публикуют.

sharp ставится через npm i sharp или находится через NODE_PATH. Nunito взят из официального google/fonts, ofl/nunito/Nunito[wght].ttf, лицензия в sources/OFL.txt. Генераторы являются источником геометрии надписей; ручные правки выходного SVG будут потеряны при пересборке.

Favicon — отдельный комплект: ../favicons/README.md. Не подменять им логотип для шапки сайта.
